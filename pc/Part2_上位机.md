# Coding Day 4 Part 2 上位机

1. 双击 `5-点云地图.bat`，在 Edge 或 Chrome 打开 `http://127.0.0.1:8765/map.html`。如果页面未自动打开，可在本目录打开 PowerShell，运行 `py -m http.server 8765 --bind 127.0.0.1`，再手动打开该地址。
2. 点击 **连接蓝牙**，选择 `HC-04BLE`。同一模块请只连接一个应用。先核对页面的位姿、点云及下方任务时序是否更新，再放车到场地起点，车头朝 `+y`。
3. 点击 **记录 CSV**。在输入框填 X、Y（米），点击一次 **发送 GOTO**。地图也可点选坐标，点击地图本身只填输入框。页面会显示固件回传的目标、路径点和已走轨迹。需要中止时，点击 **STOP**，确认车停稳后再关闭页面。
4. 到达后点击 **结束并下载 CSV**。`HARDWARE` 是从蓝牙收到的数据，`SIMULATED` 是上位机模拟。用地面标记、尺和角度参考线量实际终点和航向，单独填入验收记录。

## 指令已发送但车不动

- 顶栏显示 **BENCH · 台架版** 时，固件锁定左右电机输出。接上电机电源也不会转动。它用于检查蓝牙、IMU、任务周期和路径生成。
- 显示 **DRIVE · 实车版** 时，查看同一行给出的故障码和 IMU 状态。`5`、`6`、`7` 分别指左轮、右轮、两侧的编码器没有检测到变化。对照左右轮最近的 PWM 指令与编码器原始计数，区分固件有在给电机指令与编码器有在反馈。PWM 字段是固件指令值，实物电机是否收到电压仍以测量为准。
- 如果能收到其他遥测却一直看不到固件版本和故障码，当前固件可能尚未包含 `A` 驱动诊断。CSV 的 `drive` 行保存这些字段，便于定位问题。

收到 **近处障碍停车** 时，检查车身四周。车头标定后，固件保留 280 mm 的全向近身保护，单个有效回波达到 250 mm 时停车。前进或倒车时，沿对应方向把保护距离扩至 400 mm，限制在距雷达中心线两侧各 145 mm 的走廊内。车头尚未标定时采用 400 mm 的全向保护。启用保护时，固件限制运动速度，为停车留出余量。收到 **LiDAR 数据过期停车** 时，检查雷达供电、串口接线和页面上的点云，等数据恢复再做试验。两种保护都适用于 `GOTO` 和 `F/B/L/R`。确认安全后重新发送所需的行驶指令。

最近回波是雷达最新有效读数中的最小距离，该回波可能位于当前行驶保护区之外。触发距离和方向在当前行驶指令因障碍停车时锁存。极坐标图按雷达原始角度绘制，0° 在右侧，角度顺时针增大。橙色标记最近回波，红色优先标记停车回波，蓝色箭头表示固件上报的车头标定方向。车头标定后，状态行同时显示相对车头角度，车头为 0°、向右为正。浏览器旋转图表只改变显示。

世界点云使用固件上报的车头标定角，把原始顺时针角转换为车体前方与左方坐标，再按逆时针航向投影到世界坐标。车头标定首次到达、改变或失效时，清除旧点云和点云栅格，保留位姿、路径和轨迹。未上报车头标定的旧固件沿用原有点云显示方式。

CSV 的 `nav` 行记录保护停车状态 `7`，`drive` 行的原因 `8` 表示障碍，`9` 表示雷达数据过期。`obstacle` 行记录 LiDAR 数据是否有效、保护区状态、最近回波和停车触发的距离与原始角度、运动方向和车头标定角。距离 `0` 表示暂无相应回波，原始角 `-1` 表示未知或未标定，Q6 角度除以 64 得到度。旧固件上报四字段 `O` 时仍可显示距离，缺少角度与运动方向的列留空。

## 轮速与航向诊断

支持 `C` 遥测的固件会显示左右轮目标速度和编码器实测速度（mm/s）、陀螺积分航向、融合航向、静止陀螺零偏（°/s），以及主动制动状态。数据与当前运行号匹配后才显示，超过 3 秒未更新时标记过期。比较直行时两轮的目标与实测值，并核对地面实际轨迹，可用于定位偏向问题。

主动制动时速度目标归零，编码器实测速度仍可反映减速过程。「驱动指令 PWM」显示带符号的驱动指令，制动时可显示为 `0 / 0`。`C` 遥测中的制动标志会单独显示「主动制动，电桥双输入高电平」。CSV 的 `control` 行按原始单位记录 `left_ref_mm_s`、`right_ref_mm_s`、`left_actual_mm_s`、`right_actual_mm_s`、`gyro_yaw10`、`fused_yaw10`、`bias_mdps` 和 `brake_active`。航向原始值除以 10 得到度，零偏除以 1000 得到 °/s，制动标志为 0 或 1。

终点区域显示收到导航终止状态后下一条 `P` 帧的里程计估计。收到最后两点后，航向差以路径最后一段的方向为基准。`timing` 行包含任务激活次数、最近两次的间隔和最大执行时间，单位为微秒。`diagnostics` 行记录队列、IMU、I2C 和串口诊断计数。固件状态 `等待 IMU` 表示标定或采样尚未就绪。

试验目标按课件文字为 `(0,1.40)`、`(-0.70,0.70)`、`(0.70,-0.70)`。第三个点的课件示意图画在 `(0.70,+0.70)`，应先与 TA 核对现场路线。

终端方式可用 `py ble_cmd.py --name HC-04BLE`。命令为 `GOTO 0 1.4`、`STOP`，保留原工程的 `F300`、`B300`、`L90`、`R90` 和 `S`。浏览器和终端共享同一 BLE 设备，使用其中一个。

未连接时可点击 **模拟模式** 检查页面。模拟模式无法发送指令。

## USB 台架查看

如果烧录了台架版，可通过 ST-LINK USB 虚拟串口接收相同的 ASCII 数据。Windows 设备管理器中查看 `STMicroelectronics STLink Virtual COM Port` 对应的端口，此电脑此前是 `COM4`。

在本目录打开 PowerShell，运行下方命令。所需串口模块可用 `py -m pip install pyserial` 安装。

    py serial_console.py COM4 115200

能连续看到 `P`、`RT`、`N`、`T`、`D` 即表示所列类别的遥测已运行。输入一次 `GOTO 0 1.4` 可检查导航状态与 `W` 路径点。输入 `STOP` 应看到 `N` 回报已停止。USB 台架版的电机保持禁用，在桌面上即可查协议和时序。蓝牙导航验收用 HC-04BLE。
